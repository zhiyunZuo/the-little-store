## 这是一款什么样的游戏

《小小的店》是一款**像素风心理支持叙事游戏**。

你不是英雄，也没有任务清单——你是某个雨夜，留在一间小便利店里的**店长**。

灯亮着，门开着，客人会自己推门进来。他们有的话多，有的整晚沉默；有的带着刺，有的只是累了。你不需要拯救谁，只需要**在这里**：愿意听，或者愿意陪着坐一会儿。

> 我们没有办法让外面的世界变得温柔。
> 所以只好先把这里的灯开着。

## 玩法

游戏提供两种对话方式，随心切换：

| 模式 | 说明 |
| --- | --- |
| **✎ 自己说** | 在柜台前，亲手打字，对客人说点什么。 |
| **✦ 自动回复** | 不想打字时，把回应交给世界，故事会自己继续。 |

除了柜台前的对话，整座小镇和「你」的生活都会**自己往前走**——昼夜流转、天气变换、偶发的小事、客人之间彼此认识。你只需要偶尔推门、偶尔落座、偶尔，留一句话。

## 你会遇见的人

店里来来去去的，是一群有真实inner world的人。每个人都带着**表层性格 / 内心世界 / 防御方式**，有自己的作息和天气偏好：

- **凛** —— 安静、礼貌、木讷；其实害怕打扰别人，又渴望被看见。
- **飒** —— 尖刻、直接、不耐烦；用刺保护自尊，其实很怕被拒绝。
- **桃** —— 开朗、爱开玩笑；用热闹盖住不安，却真心喜欢生活。
- **渡** —— 疲惫、话少；长期透支，不敢停下来。
- **舞** —— 温和、爱读书、有点迷糊；怕让家人失望，喜欢小小的确定感。
- **秀** —— 傲慢、挑剔、毒舌；用优越感盖住深深的孤独。
- **茂** —— 随和、话多、热心的邻居；老伴走了，习惯了一个人。
- **宵** —— 安静、疏离、夜行；长期失眠，怕打扰也怕被靠近。

他们不是NPC数据，而是**生活在同一个世界里的人**：会在街上偶遇、会记得你上次说的话、会在雨天脚步慢下来。

## 特别的角落：Shelter

店里还有一个小小的角落——没有人规定它应该叫什么，后来，大家叫它 **Shelter**。

> **Shelter · 一个可以暂时不赶路的地方**

你可以在这里独坐、发呆，或者悄悄放下一本书、一件旧物。它会一直留在那里，像谁写给后来人的一句话。

## 设计与体验

- **低饱和像素美学**：无炫光、无粗重动画，缓动过渡，安静克制。
- **连续场景动画**：从夜色里，同一画面缓慢亮起——灯、门、雨、暖光，一气呵成。
- **环境音（Web Audio 实时合成）**：门铃、钢琴、暖垫和弦、城市底噪。**没有雨声**——只留雨落在玻璃上的安静。
- **单文件、零依赖**：一个 `index.html` 就是全部，打开即玩，无需安装、无需联网。
